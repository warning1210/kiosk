# 요구사항 우선순위 (P0/P1/P2)

`아이스크림 키오스크 요구사항 분석표 v2.0`의 우선순위(상/중/하/제약)를 P0/P1/P2 체계로 재정리한 문서.

- 매핑 기준: 상→P0, 중→P1, 하→P2
- 제약(BR-012~015)은 우선순위가 아니라 특정 역할에게 금지된 기능이라 별도 표기
- 공통기능(S-0xx)과 백로그(B-001)는 원문에 상/중/하 표기가 없어서, "없으면 서비스 진행 자체가 위험한가"를 기준으로 새로 판단함
